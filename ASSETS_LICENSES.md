# Asset & licence register

This register lists **everything** that ships in the Somewhere Else website and its licence status. It is enforced in CI by `npm run licenses` (see `scripts/check-licenses.mjs`), which fails the build if any installed package is not on a free/open-source allow-list.

_Last verified: 2026-11-12 against the exact versions pinned in `package-lock.json`._

## 3. Art, audio and music

**There are no external art, texture, model, HDRI, sound or music files.** All content is original and generated at runtime by code in this repository (MIT):

|---|---|

## 4. Services, APIs, tracking

None. The site makes **no network requests** other than loading its own static files: no analytics, no CDNs, no fonts from third-party servers, no API keys, no accounts.
